# HRMS v25.8 fixes

- Corrected whole-day holiday date handling across UTC/IST, including legacy records.
- Independence Day is canonicalized to 15 August even if an older migration saved it on 14 August.
- Attendance calendar now maps holidays using semantic calendar dates rather than server timezone instants.
- Holiday planner API returns corrected calendar dates; repair endpoint now repairs legacy dates safely.
- HR assistant understands tomorrow/day-after-tomorrow holiday questions.
- HR assistant can answer absent-by-team questions such as "Who is absent today in Sales team?".
- HR assistant handles birthday and work-anniversary questions and has a Gemini-grounded fallback for broader read-only HR questions.
- Dashboard notice board now surfaces upcoming holidays, birthdays and work anniversaries, including completed years and automatic holiday messages.
- Added an explicit time-of-day skyline scenery layer to every non-home page instead of relying on a CSS selector that could disappear.
- Upgraded global loading overlay to a richer YouTube-style shimmer feed skeleton.
- My Favourites picker can now add any accessible page/action, not only a small hard-coded subset, and is no longer clipped by the horizontal rail.
