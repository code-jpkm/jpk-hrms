# v25.4 — whole-app visual system

Every page, not four. One CSS layer that all 23 pages inherit, because they share a
class vocabulary (`nexus-page`, `premium-hero`, `premium-section-card`, `nexus-table`,
`check`, `form-grid`, `tabs-bar`, `side-drawer`, …). Restyling that vocabulary lifts
Payroll, Attendance, Employees, Leave, Shifts, Holidays, Notices, Recruitment,
Hierarchy, Permissions, Probation, Biometric, Birthdays, Company Settings, Admin
Access, Attendance Rules, AI Assistant, Dashboard, Document Studio, Account, Home and
Login together.

## The design direction

The subject is a metals manufacturer in Kolkata; the users are HR staff at desks plus
factory and office workers. You liked the home page's watercolor sunset, so the thesis
is: **carry that light across the app, but keep it at the edges so the data stays
crisp.**

**Palette** — drawn from the skyline rather than picked at random:

| Token | Hex | Role |
|---|---|---|
| `--ink` | `#221f35` | deep plum-ink, warmer than black |
| `--paper` | `#faf8fc` | barely-violet page |
| `--wash` | `#f2eefb` | table headers, group rows |
| `--indigo` | `#5b4fc4` | primary |
| `--ember` | `#e07a4f` | foundry heat — payroll and money |
| `--verdigris` | `#2e8f86` | patina — people and positive states |

**Signature** — a watercolor wash behind every page header, capped by a hairline that
runs indigo → ember → verdigris across the full width. It is the visual thread back to
the home page you like, and it appears on all 23 pages.

**Structure that means something** — section cards carry a left ledger rule tinted by
domain: ember on Payroll, verdigris on People, indigo on Attendance. It encodes where
you are rather than decorating.

**Typography** — numbers are the product here, so every table cell, stat, salary
figure and calendar count is set in tabular figures. Columns align and a changing digit
no longer shifts the row. Headings tightened to -0.032em with a real scale.

## Specific complaints addressed

- **Oversized checkboxes** — now a global 16px box with `accent-color`, everywhere,
  including the employee picker and the permission matrix.
- **Long data flooding the page** — `.premium-collapsible` is a proper folded
  disclosure with a count chip and a chevron; the pages already use this class.
- **Tables** — sticky tinted headers, hairline rows, hover, rounded container,
  horizontal scroll preserved on mobile.
- **Empty states** — an invitation to act rather than a grey box.

## Reviewed, not assumed

I rendered the real class vocabulary in a browser and screenshotted it at 1440px,
1340px and 390px, then fixed what the screenshots showed:

1. The signature wash was too faint to read — strengthened.
2. Hero buttons wrapped onto a second line — hero switched to a proper flex row.
3. The accent hairline was clipped to 300px: a legacy `.premium-hero:after{width:300px}`
   beat my `inset`, since an explicit width wins over `right`. Fixed with `width:auto`.
4. On mobile the hero had a dead gap — a legacy `min-height:146px` combined with
   centre alignment. Hero now stacks with full-width actions under 820px.
